# Archived Legacy Scenario YAML

This directory keeps the retired APTL-local scenario format and prime-scenario decisions.
Status reviewed: 2026-11-06.
These source records are not catalog entries or public startup inputs.
The supported runtime does not parse them.

## Inspect the archive

1. Read the date and status notice on each record.
2. Use Git history for the source revision that a historical claim describes.
3. Keep original decisions, commands, and evidence intact.
4. Use the [current scenario reference](../../docs/reference/techvault-scenario-overview.md) for maintained facts.
5. Use the [authoring guide](../../docs/sdl/index.md) for current pack and SDL work.

Ordinary startup uses the acquired pack catalog.
The local `scenarios/catalog.json` serves explicit research fixtures, separate from this archive.

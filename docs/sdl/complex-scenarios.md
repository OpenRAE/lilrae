# Historical Complex Scenario Designs

SDL workstream. They are no longer current authoring guidance.

Current scenario work should use RAES SDL, released environment packs, and the
TechVault RAES gate documents. The historical APTL-local YAML fixtures that
informed the old designs no longer exist. ADRs keep the design record.

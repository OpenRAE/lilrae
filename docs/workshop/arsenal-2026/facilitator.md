# Review The Arsenal Facilitator Procedure

Use this guide to assess the historical presenter flow before planning a separate event.
You need the archived release context and an approved isolated environment for any reenactment.
The result is a reviewed sequence and an explicit list of obsolete dependencies.
Do not run archive commands on the developer workstation or a shared host.

Read the [original facilitator record](records/facilitator.md) as historical evidence.
Its attack, SOC, fix, retest, and reset instructions belong to the August 5, 2026 range.
It includes retired TheHive and Cortex integrations, fixed addresses, manual repairs, and event credentials.
Do not copy those into current delivery instructions.

Before a new workshop, complete [current setup](../setup.md) and prove the [learner route](../walkthrough.md).
Keep operator diagnostics separate from participant proof.
Use [the QA review](qa.md) to distinguish observed event results from proposed outcomes.
The sections below preserve links into the original record.

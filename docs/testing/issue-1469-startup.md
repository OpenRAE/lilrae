# RPT control startup

LilRAE uses RAE 11.0.0's published random-value recipes and content references.
Private files are scoped to the admitted run. Retries reuse the value; a fresh
run gets a fresh value. Generated bytes do not enter plans or public reports.

Initial creation validation reads service configuration and logical state
through existing container operations and native APIs. It uses the existing RAE
realization report. This change adds no ongoing snapshots or final-state SDL.

Runtime tests run only on isolated GCP VM `test-1469` in `prod-mgau4w`.
Existing RPT checkouts remain unchanged. The retained temporary RPT checkout
contains the merged startup-adapter fix from
[PR 47](https://github.com/Heron-AI-Security/reproducible-purpleteam/pull/47).

- RAE 11 compatibility tests: 60 family cases passed.
- Preparation and startup regression tests: 49 cases passed.
- Mutation checks detected missing generated-value validation and reuse across runs.
- Full startup, service readiness, initial validation, status/access, teardown and
  fresh restart have not yet passed.

Keep the temporary checkout and test VM until delivery verification is complete.

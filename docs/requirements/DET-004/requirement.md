## Statement

The platform shall align with the Continuous Threat Exposure Management (CTEM) workflow phases: scoping (define attack surface), discovery (identify exposures), prioritization (rank by risk), validation (verify exploitability and detection), and mobilization (operationalize fixes).

## Rationale

CTEM is Gartner's recommended framework for continuous security validation. Aligning APTL's workflow with CTEM phases makes it legible to security teams already adopting this framework.

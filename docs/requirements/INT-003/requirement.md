## Statement

The platform shall include scenario coverage for MITRE ATLAS (Adversarial Threat Landscape for AI Systems) techniques, enabling exercises that test attacks against and by AI systems.

## Rationale

ATLAS defines 14+ AI agent attack techniques not covered by ATT&CK. As APTL is itself an AI agent platform, testing AI-specific attack/defense scenarios is uniquely relevant.

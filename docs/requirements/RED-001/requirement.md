## Statement

The system shall provide a Kali Linux container with pre-installed offensive security tools including nmap, nikto, sqlmap, impacket suite, netexec, smbclient, ldapsearch, hashcat, and standard penetration testing utilities.

## Rationale

Kali Linux is the industry-standard penetration testing distribution.

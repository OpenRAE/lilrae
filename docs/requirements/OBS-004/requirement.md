## Statement

The platform shall provide a real-time observability dashboard during running scenarios showing live agent actions, detection events, scoring progress, and system health in a unified view.

## Rationale

Currently all analysis is post-hoc. Operators need real-time visibility into what agents are doing and how defenses are responding, especially for safety monitoring of autonomous operations.
